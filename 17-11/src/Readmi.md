
# O Senhor dos Mercados II

## Sobre o projeto

O Senhor dos Mercados II é um RPG desenvolvido em TypeScript.

O projeto foi criado para praticar conceitos de Programação Orientada a Objetos.

O jogador controla um integrante da Sociedade e enfrenta inimigos das Redes Alfa e Ômega para salvar o Cupom Único.

## Personagens

- Seu Zé: Guerreiro
- Fredo: Curandeiro
- Samuel: Guardião
- Diegolas: Arqueiro

## Inimigos

1. Fiscal de Preços da Rede Alfa
2. Operador de Ofertas da Rede Ômega
3. Balrog do Boleto

## Tecnologias utilizadas

- Node.js
- TypeScript
- readline-sync

## Instalação

Instale as dependências:

npm install

## Execução

Execute o projeto em modo de desenvolvimento:

npm run dev

## Compilação

Para compilar o TypeScript:

npm run build

## Executar a versão compilada

npm start
